# Relaxation Frequency Phase Algorithm

Исследовательский Python-проект для обработки сигналов напряжения приложенного к биообъекту и току протекающему через него в ходе радиочастотной абляции. Проект предназначен для фильтрации сигналов, определения фазового сдвига между напряжением и током и оценки релаксационной частоты ткани. Электрические свойства ткани рассматриваются в рамках эквивалентной модели параллельной RC-цепи.

В проекте реализованы:

- генерация сигналов с учтом различных параметров реальных генераторов и измерительных систем;
- обработка экспериментальных данных;
- моделирование шума и параметров измерительной системы;
- полосовая фильтрация;
- различные методы определения фазового сдвига;
- локальный и глобальный анализ чувствительности;
- статистическое сравнение точности и устойчивости алгоритмов.

## Установка проекта

1. Установите [Visual Studio Code](https://code.visualstudio.com/), [Python](https://www.python.org/downloads/) и [Git](https://git-scm.com/downloads/).

2. В Visual Studio Code установите расширения **Python** и **Jupyter**.

3. Нажмите `Ctrl + Shift + P`, выберите `Git: Clone` и вставьте ссылку:

```text
https://github.com/Gr-a-f/Relaxation_frequency_phase_algorithm.git
```

4. Откройте терминал Visual Studio Code и создайте виртуальное окружение:

```powershell
python -m venv .venv
```

5. Активируйте окружение:

```powershell
.venv\Scripts\Activate.ps1
```

6. Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

7. Откройте демонстрационный notebook:

```text
notebooks/Pair_of_signals_demonstration/generated_signals.ipynb
```

8. Выберите `.venv` в качестве Jupyter Kernel и запустите ячейки по порядку.


## Запуск демонстрационных файлов

Notebooks из каталога `notebooks/Pair_of_signals_demonstration` предназначены для полной обработки и визуализации отдельных пар сигналов напряжения и тока.

Каждый notebook работает с определённым источником данных: модельными сигналами, экспериментальными измерениями, результатами моделирования или данными FPGA.

Основной демонстрационный пример:

```text
notebooks/Pair_of_signals_demonstration/generated_signals.ipynb
```

Он содержит последовательный пример:

1. генерации сигналов напряжения и тока;
2. добавления шумов и искажений;
3. цифровой фильтрации;
4. спектрального анализа;
5. определения фазового сдвига различными методами;
6. визуализации и сравнения результатов.
